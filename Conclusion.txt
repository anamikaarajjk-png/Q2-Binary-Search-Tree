FINAL CONCLUSION

The given ISBN keys were successfully inserted into a Binary
Search Tree. Inorder, preorder and postorder traversals were
performed successfully.

For the given dataset, BST Search required fewer comparisons
than Linear Search for all three search keys: 25, 55 and 90.

Therefore, BST Search provides better search performance for
this dataset. However, an unbalanced BST can have O(n) worst-case
search complexity.

Hence, a reasonably balanced BST is suitable when frequent
search operations are required.
